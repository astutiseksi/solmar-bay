An original open-world crime game in the spirit of GTA 6: explore the sun-soaked coastal city of Solmar Bay on foot and by car, steal cars, outrun the police through five wanted levels, and finish six story missions as Milo Reyes works off a debt to fixer Lena Cruz — ending with the biggest score the city has ever seen. Traffic and pedestrians, combat with fists and a pistol, a HUD with a live minimap, day-and-night light, hidden packages, and a save that keeps your progress. No assets, names, music or map from any commercial game — the city, characters, vehicles and story are all invented.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network: `game/` is plain static files. `?seed=N` fixes the city; `?shot=start|play|chase|heist` stages a screenshot scene.
